# RNGPW
A simple powerful Random Password Generator built with React. This application generates random passwords with customizable options for length, inclusion of special characters, and more. The generator also provides feedback on password strength and includes functionality to copy the generated password to the clipboard.

# Features
Customizable Length: Generate passwords with a length between 1 and 25 characters.
Special Characters: Option to include or exclude special characters in the password.
Password Strength Indicator: Visual and text-based feedback on the strength of the generated password (weak, medium, strong).
Copy to Clipboard: Easily copy the generated password to your clipboard.
Show/Hide Password: Toggle visibility of the generated password.
Dynamic Styling: Animated interactions, such as button presses and password strength transitions.
